	// [ Basic AI Movement Tutorial ]

		// * Never
		// + Every 05''-00
		// + Random(20) < value( "Freddy AI" )
			// Freddy Collision Character : Set Move to 1

		// // Here's a sample of FNaF AI. (Except for the Never condition) It's actually not that complicated. The every 5 seconds condition makes the event run once every 5 seconds.
		// 
		// The "Random(20) < AI Level" condition can seem a little bit confusing at first, but if you double-click it and the general values menu comes up, it starts to make a lot more sense.
		// 
		// When the event is running, a random number between 0-19 is picked. (It's important to note that the Random number never goes up to what you set it to, just a maximum of one number below it.)
		// Then the randomly generated number will be compared to the current AI value (In this case, it's Freddy's.) If the number is lower than the current AI value, then the animatronic will get called to move. (Alterable Value A set to 1.)

		// * Never
		// + Move of Freddy Collision Character > 0
		// + Freddy Collision Character is overlapping Cam 01 Text
			// Freddy Collision Character : Set Move to 0
			// Freddy Collision Character : Set position at (0,0) from Cam 03 Text

		// // This event above is the event to make him actually move. The move value being set to 1 is the main condition for him to move.
		// 
		// The move value is set to 0 and then he is moved from a one location to another. This is just a sample from the Freddy example character, you can look at the full AI a few event group above this.
		// 
		// This can be used for a lot more than just moving around. Let's say if Freddy is in your office and want him to kill the player faster depending on the AI value, this can be done too, just have the "Move > 0" condition attached to the jumpscare event. But I would not recommend doing it that way because of the nature of RNG, There's a chance Freddy will never kill you. I'd recommend just using a timer for that. That's just an example of what can be done. The amount you can really do with this is basically infinite.
		// 
		// Now this is just very basic AI Movement, there's still a lot to to do to have a fully implemented animatronic, such as camera images, footstep sounds, camera blackouts, jumpscares, etc. But this is a good start to making one.
		// 
		// The other example animatronics are rather complicated and have different mechanics than just moving around cameras, so I don't even know where to start to explain exactly how they work. However, I did try to simplify their code as much as possible, so hopefully they can be understood.
