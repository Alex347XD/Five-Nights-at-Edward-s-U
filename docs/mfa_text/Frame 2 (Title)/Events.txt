	// // How to setup the update engine:
	// 1: Go to pastebin.com, create a new paste, and give it a name.
	// I advise against Paste Expiration or Password Protected pastes.
	// 
	// 2: Enter your version number into the Paste.
	// You will need to update this Paste each time you make a new version.
	// This should always be the latest version of your application.
	// Example: 1.0.0
	// 
	// 3: Click Create and then copy the Pastebin ID.
	// Clicking create will automatically redirect you to your Paste.
	// The Pastebin ID will be in the link. (pastebin.com/XXXXXXXX)
	// Don't copy the entire link.
	// 
	// 4: Open properties of the Update Object, go to the values tab, and paste your Pastebin ID into the "PastebinID" box in Alterable Strings.
	// 
	// 5: Put the current version of your application in the "thisversion" alterable string. This will be your actual version number that gets compared to your Paste. This won't get recognized as a number, but only as a string. So putting in a lower number into the Paste after releasing this application will still get recognized as an update.
